# Lesson 1

Notes on the basics.

## Notes

* C was created to design the UNIX operating system.
* C is ***modular***. C code can *(and should)* be written in routines called *functions*.
* C is compiled. The compiler takes your source code file as input and produces a disk file containing the 
machine language instructions that correspond to your source code statements.
    - The machine language instructions are called *object code*
    - The disk file containing them is called an *object file*
* ***Linking*** is the process of combining your object code from compiling your source code file with object code from
the function library to create the final executable program.

## Progression from *source code* to *object code* to *executable program*

1. Use editor to **write source code**

2. **Compile source code** file to produce object code

3. **Link object code** from library files with your object code to **produce an executable program**.
